## 机房位置决定体验下限，配置只决定上限

物理距离带来的延迟无法用配置抵消。香港机房到东京大约 53ms、到新加坡 37ms，到欧洲和北美则在 170–210ms 区间。这是网络传输的物理下限，换 8 核 16G 也压不下来。反过来，把服务器放在客户隔壁，1 核 1G 的机器打开产品页也可能比远端的高配机更快。

所以第一步永远是把客户地图摊开：

**客户在欧美**——美国机房。美东的纽约、阿什本、芝加哥贴近欧洲和美东本土，美西的洛杉矶、圣何塞、西雅图对亚太回程更友好，也方便你自己在国内登后台。这一条几乎所有建站老手口径一致。

**客户在东南亚、东亚、中东、港澳台**——香港、新加坡、日本三个点。日本到东亚和东南亚的延迟表现与香港接近，同时在日区本地服务、流媒体、游戏、电商平台上有一层额外优势：日本原生 IP 在当地平台眼里就是本地用户。

**客户分布很散，两边都有**——优先保大头，剩下那部分靠 CDN 补。Cloudflare 免费版能把静态资源推到离用户最近的节点，但首字节响应仍然取决于源站位置，不能指望 CDN 把源站搬到另一个洲。

日本机房的问题也说清楚：它对欧美客户不占优势，170–210ms 这个量级和香港机房差不多。如果你的询盘七成来自德国、美国，日本机器给你的只是“国内后台好管理”，不是“客户打开快”。这种情况下更该看官网的美国产品线，而不是因为日本套餐便宜就下手。

## 配置档位：内存和磁盘 IO 才是瓶颈，核数不是

WordPress 加 WooCommerce 跑起来，真正吃的是内存和磁盘 IO。CPU 核数在这个场景里是最不紧张的一环——一个正常优化的外贸站，日均一两千 PV，双核和四核的差别你基本感知不到，但内存从 1G 到 2G 的差别立刻能感觉到。

按站点规模对应下来：

- **1GB 内存**：只能跑一个“干净”的站。WordPress 本体加几个必要插件，内存要压在 600MB 以内，重型页面编辑器、多合一 SEO 插件、实时聊天 widget 这类东西得砍掉。适合产品页个位数、流量几百 IP 的展示站。
- **2GB 内存**：日 PV 千级的甜点档。WooCommerce 装起来、产品图几百张、缓存插件开着，余量还算舒服。正式运营的独立站建议从这里起步。
- **4GB 内存**：能稳跑 2–3 个轻量 WordPress 站点，或者一个大站加多语言、会员、促销插件。
- **8GB 内存**：5 个站以上，或者站群、ERP/CRM 集成这类吃内存的负载。

硬盘看类型不看数字。NVMe 的 4K 随机读写能力直接决定后台点一下菜单要等多久、WooCommerce 结算页转几圈。同样是 20G，SATA SSD 和 NVMe 的体感差得明显。

**年付版和月付版是两种东西。** 499 元/年的特价版带宽 100Mbps、流量 600GB/月，和 88 元/月的基础版（300Mbps、3000GB）不是同一档体验。看到“每月 41 元”就以为买到了基础版，是这条产品线上最容易踩的误解。

## 拿到机器之后：建站流程

这套流程在哪个商家买机器都通用，熟练的话半天能上线，第一次做最多一个周末。

1. **选系统**：Debian 12 或 Ubuntu 22.04。这两个版本的软件源新、社区资料多，出问题好搜。官方支持安装 Windows，但跑 WordPress 没必要，占资源还多花钱。
2. **开 BBR**：官方页面专门提醒了两次“建议开启 BBR 加速”，跨洲访问时它对吞吐的提升很明显，几行命令的事。
3. **装面板**：宝塔或 1Panel，图形化管理 Nginx、PHP、MySQL，不用记命令行。不想要面板也可以手搭 LNMP，但维护成本高。
4. **部署 WordPress**：面板里一键部署，绑定域名，Let's Encrypt 免费 SSL 证书点一下就签发。
5. **装主题和 WooCommerce**：Astra 或 Storefront 这类轻量主题，别用功能大而全的多用途主题——它们加载的脚本能拖慢整站。
6. **接 Cloudflare**：免费版够用，静态资源走 CDN，顺便挡掉一批爬虫和垃圾请求。
7. **跑 PageSpeed Insights**：按建议开缓存、压图片、延迟加载非首屏资源。这一步的收益通常比升级配置更大。

插件是外贸站最大的隐形负担。能用代码或主题设置解决的，就别装插件；每装一个都在吃内存和请求数，1GB 内存的机器尤其经不起堆。

## 常见问题

**1GB 内存能跑 WooCommerce 吗？**
能装能跑，但要压得很紧。WordPress 本体、WooCommerce、缓存插件、SSL，加起来内存占用要控制在 600MB 以内，重型页面编辑器、多合一 SEO 套件、实时聊天工具都得省掉。产品超过几十个、开始投广告带流量之后，1GB 会成为明显的天花板。预算允许就直接上 2GB。

**年付套餐第二年续费会涨价吗？**
官网当前只公示了首期价格，没有单独标注续费价。下单时在结账页确认循环计费金额，是唯一可靠的办法。不要默认“年付等于锁价”。

**日本机房需要备案吗？**
不需要。境外服务器不涉及 ICP 备案，域名解析过去就能访问，也不用幕布拍照和营业执照。这也是外贸站普遍不用国内主机的原因之一。

**IP 被平台拉黑了能换吗？**
这条产品线的公开页面没有写换 IP 的政策和收费标准。真遇到问题，开工单问清楚比自己猜快。原生 IP 的纯净度是它主打的东西，但没有任何商家能保证每一个 IP 在所有平台上都干净。

**流量用超了会怎样？**
套餐标注的是月流量额度，超出后的处理方式官网没有明示。如果你的业务流量波动大、不可预测，与其赌超量后的处理方式，不如直接选不限流量的 Lite 或 Pro，把不确定性买断。

**一台机器能放多个站吗？**
能，看内存。按经验，2GB 跑一个正式站刚好，4GB 能稳跑 2–3 个轻量站，8GB 可以上 5 个以上。多站还要考虑硬盘——每个站的数据库和图片都占空间，豪华版的 40G 比进阶版的 20G 更适合这种用法。
